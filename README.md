# LibreraCommander

Native macOS dual-pane file manager: Finder-style list and grid panels with previews, an info panel
(system info, text / Markdown / HTML viewer, audio & video player with metadata, archive and folder info),
a built-in terminal, Finder-style Quick Actions, and Android / iOS simulator device panels.

Requires macOS 14 Sonoma or later (Apple silicon or Intel).

## Install

With [Homebrew](https://brew.sh):

```sh
brew install foobnix/tap/libreracommander
```

Update with `brew upgrade libreracommander`.

Or download the latest DMG from [Releases](https://github.com/foobnix/LibreraCommander-releases/releases/latest)
and drag LibreraCommander to Applications.

This repository only hosts the release builds.
